Hashing & Digest

Home Imports Packages

The std.hash provider exposes hashing and checksum functions backed by D's std.digest module. It supports MD5, CRC32/CRC64 (ECMA), SHA-1, SHA-2 family, and MurmurHash3 (x86 32-bit).

Import

import std.hash
// or
import std.digest

API

Available functions

  • md5(s: string) -> string (hex)
  • crc32(s: string) -> int
  • crc64(s: string) -> int
  • sha1(s: string) -> string
  • sha224(s: string) -> string
  • sha256(s: string) -> string
  • sha384(s: string) -> string
  • sha512(s: string) -> string
  • sha512_224(s: string) -> string
  • sha512_256(s: string) -> string
  • murmurhash3(s: string, seed: int = 0) -> int

Example

import std.hash

let string s = "abc"
print(md5(s))        // 900150983cd24fb0d6963f7d28e17f72
print(sha256(s))     // ba7816bf...
print(crc32(s))      // 891568578
print(crc64(s))      // 7372421403230734421
print(murmurhash3(s))
print(murmurhash3(s, 42))
