Built-ins

These helpers are available everywhere without imports:

  • osName() → string: a lowercase OS identifier (e.g., linux, macos, windows).
  • osVersion() → string: a human-friendly OS/kernel version string.
  • cpuArch() → string: CPU architecture (e.g., x86_64, aarch64).
  • args() → list<string>: command-line arguments passed to the program (excluding the program name).

Also available

  • sleep(ms: int) — pause execution for milliseconds.
  • len(x) — length of strings, lists, dicts, bytes.
  • safeCast(T, value) — strict conversions returning Result<T>.

Example

// Print environment info
print("OS: ${osName()} - ${osVersion()}")
print("CPU: ${cpuArch()}")

// CLI usage
let list<string> av = args()
if av.length == 0 do
    print("Usage: tool <name> <n1> <n2> ...")
else
    let string name = av[0]
    print("Hello ${name}")
    var int total = 0
    for i in 1 .. av.length - 1 do
        let string s = av[i]
        if s.matches(regex("^[-]?\\d+$")) do
            total = total + s.toInt()
        end
    end
    print("Sum=${total}")
end

Note: OS name/version and CPU arch vary per system; tests should not assert exact values.
