Overview

Duende supports JSDoc-style block comments using /** ... */. At this stage, these comments are treated like regular comments by the lexer and parser and are ignored during compilation.

Example

/**
 * Adds two integers and returns the sum.
 * @param {int} a - First addend.
 * @param {int} b - Second addend.
 * @returns {int} Sum of a and b.
 */
int add(int a, int b) do
    return a + b
end

/** Entry point */
int main() do
    let int s = add(2, 3)
    print(s)
end

Future phases may parse and surface JSDoc for tooling (e.g., hover docs, type hints). For now, you can freely document your code without affecting behavior.
