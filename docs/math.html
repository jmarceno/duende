Extended math helpers live in the standard library module std.math. You must import it to use any math functions.

Available functions

  • Core: abs(x), min(a,b), max(a,b), floor(x), ceil(x), round(x), sqrt(x), pow(a,b), log(x), exp(x)
  • Trig: sin(x), cos(x), tan(x) (radians)
  • Degrees helpers: sinDeg(x), cosDeg(x), tanDeg(x), toRadians(deg), toDegrees(rad)
  • Formatting: roundTo(x: float, n: int), formatFloat(x: float, n: int)
import std.math

print(roundTo(3.1415926, 2))    // 3.14
print(sinDeg(90))               // 1
