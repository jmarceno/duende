Syntax

Lambdas use { params -> expr } form. They can capture variables from the surrounding scope.

let int x = 5
let auto inc = { n -> n + 1 }
print(inc(x)) // 6

let int y = 5
let auto incCaptured = { n -> n + y }
print(incCaptured(2)) // 7
