Available constructors and helpers

  • Result: Ok(value), Error(message: string)
  • Maybe: Some(value), None
  • Unwrap: x ? else expr operator
  • Strict casting: safeCast(T, value) -> Result<T> where T is int|float|string|bool|bytes

Result

Use Ok(value) for success and Error(message) for failure.

Result<int> safe_divide(int a, int b) do
    if b == 0 do
        return Error("division by zero")
    end
    return Ok(a / b)
end

let Result<int> r = safe_divide(10, 0)
let int v = r ? else -1
print(v) // -1

? else operator

Extract a value or compute a fallback when the wrapper is Error or None. The subject expression runs once. The fallback expression runs only in the failure case, and then only once.

The type of x ? else fallback is the type of fallback. On success, the payload is converted to that type, so Result<Status> ? else "error" yields the status name. On failure, the fallback value is the result and the payload is not read.

let Result<float> parsed = parse_number("invalid")
let float f = parsed ? else 0.0

Where Ok, Error, Some, and None get their type

Ok, Error, Some, and None take the wrapper type from the nearest declaration, argument, assignment, or return. An int payload is the 64-bit int, including a literal such as Ok(3000000000) stored in Result<int>. A literal stored in Result<float> or Maybe<float> uses float.

Inside a function that returns Result or Maybe, a constructor with no tighter context uses that return type. With no context at all, Error is Result<string> and None is Maybe<string>. Ok and Some then use the payload's type, and an int literal is still int.

let Result<int> bad = Error("nope")
let Maybe<int> empty = None
let Result<float> widened = Ok(3)

int take(Result<int> r) do
    return r ? else -1
end

take(Error("missing"))

Typed list literals also provide this context, including nested lists: let list<Maybe<float>> values = [Some(3), None]. An inferred Some keeps its payload type. The compiler checks Ok and Some payloads against their expected types and requires an Error message to be a string. A known non-wrapper subject such as 3 ? else 9 is rejected.

One Result and one Maybe

Result and Maybe are the same types in every module. A function in one file can return Ok, Error, Some, or None, and another file can store that value, pass it on, or unwrap it.

Maybe

Some(value) or None represent optional values. List first and last, and dictionary get, return Maybe so a missing element is not the value -1.

let Maybe<string> maybe_some = Some("Hello")
let string s1 = maybe_some ? else "default"

let Maybe<string> maybe_none = None
let string s2 = maybe_none ? else "default"

Pattern matching

Match on Ok(x) and Error(e). A match on a Result must handle both, or end with _. See Pattern Matching.

Strict casting with safeCast

Use safeCast(T, value) to perform a strict conversion that returns Result<T> instead of throwing. The first argument is a type literal (int, float, string, bool, bytes).

let Result<int> x = safeCast(int, "10")     // Ok(10)
let Result<string> s = safeCast(string, 123) // Ok("123")
let Result<int> bad = safeCast(int, "NaN")   // Error("NaN")
let Result<int> err = safeCast(int, "abc")   // Error("...parse error...")

// Handle with ? else or pattern matching
let int n = x ? else -1
match bad do
  Ok(v) -> print(v)
  Error(e) -> print(e)
end
