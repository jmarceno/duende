Database

Home Packages

Duende provides database access via the std.database package, backed by the DDBC library. Supported databases include SQLite, MySQL, PostgreSQL, and SQL Server (via ODBC). SQLite requires no server and is used in examples and tests.

Available functions and types

  • Types: DBConn, DBStmt (you can pass these between functions; using auto for parameters works and is inferred)
  • Connection: dbConnect(url: string) -> DBConn, dbClose(conn)
  • Transactions: dbBegin(conn), dbCommit(conn), dbRollback(conn)
  • Direct SQL: dbExecute(conn, sql: string) -> int, dbExecuteTry(conn, sql) -> int
  • Queries: dbQueryScalar(conn, sql: string) -> string, dbQueryAll(conn, sql: string) -> list<list<string>>
  • Prepared: dbPrepare(conn, sql: string) -> DBStmt, dbCloseStmt(stmt), dbCloseStmtTry(stmt)
  • Binds: dbBindString(stmt, idx: int, v: string), dbBindInt(stmt, idx: int, v: int), dbBindFloat(stmt, idx: int, v: float), dbBindBytes(stmt, idx: int, v: bytes)
  • Exec prepared: dbExecPrepared(stmt) -> int, dbExecPreparedTry(stmt) -> int

Setup

  • Import std.database in your Duende module.
  • No manual dependency setup is needed: Duende detects the provider and builds with ddbc via dub automatically.

Connection strings

Connection strings follow DDBC format. The ddbc: prefix is optional.

  • SQLite (in-memory): sqlite::memory: or ddbc:sqlite::memory:
  • SQLite (file): sqlite:path/to/file.db
  • MySQL: mysql://host:3306?user=USER,password=PASS
  • PostgreSQL: postgresql://host:5432?user=USER,password=PASS
  • SQL Server (ODBC): odbc://?dsn=NAME or sqlserver://host,1433?user=USER,password=PASS,driver=FreeTDS

API

import std.database

let string url = "sqlite::memory:"
var auto db = dbConnect(url)
dbExecute(db, "CREATE TABLE t (id INTEGER PRIMARY KEY, name TEXT)")

// Prepared insert
var auto st = dbPrepare(db, "INSERT INTO t (id, name) VALUES (?, ?)")
dbBindInt(st, 1, 1)
dbBindString(st, 2, "Alice")
dbExecPrepared(st)
dbCloseStmt(st)

// Queries
let string cnt = dbQueryScalar(db, "SELECT COUNT(*) FROM t")
var auto rows = dbQueryAll(db, "SELECT id, name FROM t ORDER BY id")
dbClose(db)

Passing connections to functions

You can pass a connection to other functions. Either give the parameter the explicit type DBConn, or use auto to keep it generic:

void addCustomer(DBConn db, string name, int id) do
  var auto st = dbPrepare(db, "INSERT INTO t (id, name) VALUES (?, ?)")
  dbBindInt(st, 1, id)
  dbBindString(st, 2, name)
  dbExecPrepared(st)
  dbCloseStmt(st)
end

void addCustomer2(auto db, string name, int id) do
  // Same body as above; type is inferred at call site
  var auto st = dbPrepare(db, "INSERT INTO t (id, name) VALUES (?, ?)")
  dbBindInt(st, 1, id)
  dbBindString(st, 2, name)
  dbExecPrepared(st)
  dbCloseStmt(st)
end

Transactions

Use dbBegin, dbCommit, and dbRollback for transaction control.
