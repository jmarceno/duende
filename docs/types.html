Built-in types

  • int — 64-bit integer
  • float — double-precision
  • string
  • bool
  • bytes — byte array
  • list<T> — dynamic array (must specify element type)
  • dict — associative array
  • auto — inferred type of the initializer
  • User-defined: struct, frame, enum, and protocol

Type annotations

let int a = 1
let float b = 3.5
let string s = "text"
let list<int> xs = [1, 2, 3]
let dict d = {"k": 1}
let auto n = 42 // inferred as int

Generics-like containers

Containers use explicit element types, e.g., list<int>, list<string>. Empty list literals require context: let list<string> xs = []. Algebraic results use constructor names (see Result & Maybe).

Result and Maybe

These are sum types with constructors Ok/Error and Some/None. Use the ? else operator to provide a fallback. See the dedicated page: Result & Maybe.

Type casting

Use function-like syntax to convert between core types:

let int a = int(3.99)      // 3
let float b = float("2.5") // 2.5
let string s = string(42)  // "42"
// Works with variables and expressions too:
let int n = int("10") + int(2.7) // 12

Casting relies on conversion semantics similar to D's std.conv.to. Converting malformed strings to numbers may raise a runtime error.
