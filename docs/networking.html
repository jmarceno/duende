Networking

Home Packages

Duende exposes basic TCP/UDP facilities via the std.networking package which maps to D's std.socket. Import the module and use helpers like tcpListen, tcpAccept, tcpConnect, tcpSend, and tcpRecvLine. Non-blocking readiness with timeouts is supported via cross‑platform select-style polling (POSIX and Windows).

Quick start (TCP)

import std.networking

int main() do
  var int port = 9099
  var auto listener = tcpListen(port)
  // Spawn a one-shot echo handler so client and server run in one process
  spawnEchoOnce(listener)

  // Client side
  var auto c = tcpConnect("127.0.0.1", port)
  tcpSend(c, "hello", true)
  var string reply = tcpRecvLine(c)
  print(reply)
  tcpClose(c)

  // Close server listener
  tcpClose(listener)
  return 0
end

Quick start (UDP)

import std.networking

int main() do
  // Bind server on ephemeral port and echo once in background
  var auto server = udpOpen(0)
  var int port = udpLocalPort(server)
  spawnUdpEchoOnce(server)

  // Client sends and waits with timeout
  var auto client = udpOpen(0)
  udpSendTo(client, "127.0.0.1", port, "ping")
  var string msg = udpRecv(client, 1000)  # 1s timeout
  if msg == "" do
    print("timeout")
  else
    print(msg)  # -> udp:ping
  end
  udpClose(client)
  udpClose(server)
  return 0
end

API

Available functions and types from std.networking:

TCP

  • tcpListen(port: int, address: string = "127.0.0.1", backlog: int = 10) -> TcpListener
  • tcpAccept(listener: TcpListener) -> TcpSocket
  • tcpAcceptTimeout(listener: TcpListener, out client: TcpSocket, timeoutMs: int) -> bool
  • tcpConnect(host: string, port: int) -> TcpSocket
  • tcpSend(socket: TcpSocket, data: string, addNewline: bool = false) -> int
  • tcpRecvLine(socket: TcpSocket) -> string
  • tcpRecvLineTimeout(socket: TcpSocket, timeoutMs: int) -> string
  • tcpRecvAll(socket: TcpSocket) -> string
  • tcpClose(listener|socket)
  • spawnEchoOnce(listener: TcpListener) — background one‑shot TCP echo for demos/tests

UDP

  • udpOpen(port: int = 0, address: string = "0.0.0.0") -> UdpSocket
  • udpSendTo(socket: UdpSocket, host: string, port: int, data: string) -> int
  • udpRecvFrom(socket: UdpSocket, out host: string, out port: int) -> string
  • udpRecv(socket: UdpSocket, timeoutMs: int = 1000) -> string
  • udpLocalPort(socket: UdpSocket) -> int
  • udpClose(socket: UdpSocket)
  • spawnUdpEchoOnce(socket: UdpSocket) — background one‑shot UDP echo for demos/tests

Timeouts & platform notes

Readiness waits are implemented with select on POSIX and Winsock select on Windows. If neither platform macro matches, a simple sleep loop is used as a fallback. Timeout helpers return empty strings (for UDP) or partial data read so far (for TCP line reads) if the timeout elapses.
