std.process package

The std.process package provides portable process management built on D's std.process. Import it with import std.process.

  • execute(args), executeShell(cmd) — run and capture stdout and stderr separately (Duende helper).
  • spawnProcess, wait, tryWait, kill — core primitives.
  • pipeProcess, pipeShell — redirect stdio via pipes.
  • readAllStdout, readAllStderr — convenience readers for ProcessPipes.

Available functions and types

  • Types: Pid, ProcessPipes, Redirect, Config
  • environment (dict-like)
  • spawnProcess(argv: list, ...), spawnShell(cmd: string, ...)
  • pipeProcess(argv: list, redir), pipeShell(cmd: string, redir)
  • wait(pid) -> int, tryWait(pid) -> Maybe<int>, kill(pid)
  • execute(args: list, env: dict? = null, config = none, workDir: string? = null) -> ExecResult
  • executeShell(cmd: string, env: dict? = null, config = none, workDir: string? = null) -> ExecResult
  • readAllStdout(pipes: ProcessPipes) -> string, readAllStderr(pipes: ProcessPipes) -> string

Example

import std.process

int main() do
  var auto res = execute(["/bin/sh", "-c", "echo hello && echo err 1>&2"]) 
  print(res.stdout.trim())
  print(res.stderr.trim())
  print(res.status)

  var auto p = pipeShell("printf hi && printf oops 1>&2", Redirect.stdout | Redirect.stderr)
  print(readAllStdout(p))
  print(readAllStderr(p))
  print(wait(p.pid))
  return 0
end
