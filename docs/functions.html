Declaration

Functions declare parameter and return types. Bodies use do ... end.

int add(int a, int b) do
    return a + b
end

void greet(string: name) do
    print("Hello, ${name}")
end

Auto parameter types

Parameters can use auto to defer the type and let it be inferred at each call site. This is useful for generic helpers and when working with provider-backed types like database connections.

void println(auto x) do
  print("${x}")
end

// Works with any type
println(42)
println("hi")

Under the hood, Duende emits D templates for functions with auto parameters, so you can pass values of any type without specifying the exact type.

Default parameters

Parameters can have default values using =. Default parameters must come after all non-default parameters. Defaults must be compile-time constant expressions (literals, arithmetic on literals, simple casts) and must be type-compatible.

int multiply(int a, int b = 2) do
  return a * b
end

int add3(int a, int b = 10, int c = 5) do
  return a + b + c
end

void logMessage(string: msg, string: level = "INFO") do
  print("${level}: ${msg}")
end

// Calls
print(multiply(7))      // 14
print(add3(5))          // 20
logMessage("Ready")     // INFO: Ready

Named arguments

You can call functions using named arguments with name: value. Named arguments may appear in any order and can be mixed with positional ones. Unspecified parameters use their default values when available.

int add3(int a, int b = 10, int c = 5) do
  return a + b + c
end

// Reorder freely using names
print(add3(c: 3, a: 1, b: 2))      // 6

// Omit params that have defaults
print(add3(c: 5, a: 1))            // 1 + 10 + 5 = 16

void greet(string: name) do
  print("Hello, ${name}")
end

greet(name: "World")

// Mixing positional and named is allowed; positionals fill first unfilled parameters
print(add3(1, c: 7))               // 1 + 10 + 7 = 18

Calling

let int s = add(7, 8)
greet("Duende")

Return

Use return with a value of the declared type. For void functions, return can omit a value.
