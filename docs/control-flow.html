If / elif / else

if n <= 1 do
    return 1
elif n > 10 do
    return 42
else
    return n * 2
end

Each if, elif, and else body has its own local scope. All branches are checked even when their conditions are constant.

Block expressions with try

try do ... end currently evaluates a local block. It does not catch exceptions. A return inside this block returns its value from the block, not from the surrounding function. The block uses the type expected by its declaration, assignment, argument, or return; without that context its result is inferred. Names declared inside it remain local.

let string greeting = try do
    let string text = "hello"
    return text.trim()
end
print(greeting) // hello

A block expression starts a separate loop context. break and continue may target loops inside that block, but cannot target a loop surrounding it. Both statements are rejected outside a loop, including inside methods and elif branches.

While

var int count = 1
while count < 5 do
    print(count)
    count = count + 1
end

Break and Continue

Use continue to skip to the next iteration and break to exit the loop.

var int i = 0
while true do
  i = i + 1
  if i == 3 do
    continue
  end
  print(i)
  if i == 5 do
    break
  end
end

For-in ranges

Use the range operator a .. b. Optional step is not shown in examples.

for i in 1 .. 5 do
    print(i)
end

Boolean operators

!, &&, || are supported (no word forms).

let bool a = true
let bool b = false
print(!(a && b) && (a || b))
