Available methods

  • On bytes
    • upper() -> bytes (ASCII)
    • lower() -> bytes (ASCII)
    • find(sub: bytes) -> int (index or -1)
    • slice(start: int, end: int) -> bytes
    • length property and length() method
  • Free functions
    • len(x) -> int
    • fromBytes(b: bytes) -> string

Byte arrays

Duende has a built-in bytes type for binary data. You can create it from a list of numbers or with a bytes literal using the b"..." prefix.

let bytes data = [1, 2, 255]
let bytes hello = b"hello"
let bytes world = b" world"
let bytes hw = hello + world    // concatenation
print(fromBytes(hw))            // "hello world"

// indexing and length
print(data.length)              // 3
print(data[0] + data[1])        // 3
print(data[2])                  // 255

// slicing
let bytes slice = hello[1:4]    // b"ell"
print(fromBytes(slice))

// len() builtin
print(len(hello))               // 5

// iteration
var int sum = 0
for b in hello do
    sum = sum + b
end
print(sum)

// methods
print(fromBytes(hello.upper())) // b"HELLO"
print(fromBytes(hello.lower())) // b"hello"
print(hello.find(b"l"))        // 2

Convert strings to bytes and back with toBytes() and fromBytes(...). See Strings and File I/O for examples.
