Available functions

  • print(x: any) — prints with newline; accepts expressions and formatted strings.
  • input() -> string
  • input(prompt: string) -> string (writes prompt, then reads)

print

print("Player ${name} scored ${score} points!")
print("Next level requires ${score + 5} points")

input

let string name = input()
print("Hello, ${name}")

print("Length=${(input()).length}")

let string prompted = input("Name: ")
print("Prompted: ${prompted}")

Terminal (non-interactive)

Duende exposes a minimal terminal module backed by arsd.terminal for simple TTY detection without entering interactive modes. These helpers are safe in any environment and do not change terminal state. 

import terminal

if Terminal.stdoutIsTerminal() do
    print("stdout is a terminal")
else
    print("stdout is redirected (file/pipe)")
end

if stdinIsTerminal() do
    print("stdin is a terminal")
else
    print("stdin is not interactive")
end
