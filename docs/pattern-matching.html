Match statement

string describe(int x) do
    return match x do
        0 -> "zero"
        1 -> "one"
        _ -> "many"
    end
end

Guards

match stat do
    ACTIVE if value > 0 -> s = ACTIVE
    ACTIVE if value < 0 -> return Error("Invalid value for active")
    ACTIVE -> s = ACTIVE
    INACTIVE -> s = INACTIVE
    PENDING -> s = PENDING
end

A guard is a bool expression after if. It runs only when the arm's pattern matches, and it can use the arm's bindings:

let int x = -7
return match fetch(n) do
    Ok(x) if x > 100 -> "big ${x}"     // this x is the Ok payload, not the outer x
    Ok(x) -> "small ${x}"
    Error(msg) -> "failed: ${msg}"
end

How a match runs

  • The subject is evaluated once, before any arm.
  • Arms are tried top to bottom. For each arm, the pattern is tested, then Ok(x)/Error(e) payloads are bound, then the guard runs.
  • The first arm whose pattern and guard both hold is the only arm that runs. Later guards are not evaluated.
  • A binding exists only inside its own arm (guard and body), and hides any outer variable with the same name there.

Coverage

Arms with a guard never count toward coverage, because the guard may be false. A compile error is emitted when:

  • a match on an enum leaves a value without an unguarded arm and has no _ arm (statements and expressions);
  • a match on a Result is missing an unguarded Ok(...) or Error(...) arm and has no _ arm (statements and expressions);
  • a match expression on any other type (int, string, Maybe, ...) has no unguarded _ arm. A bool subject may instead cover true and false.
  • an arm can never run because earlier unguarded arms already match everything it could match, such as an arm after _.

A match statement on an open type such as int or string may leave values unmatched; then no arm runs.

Regex pattern

match email do
    regex("^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\\.[A-Za-z]{2,}$") -> print("Looks like email")
    _ -> print("Not an email")
end

Collections lookup patterns

var list<int> numbers = [1, 2, 3]
match 1 do
    numbers[0] -> print("First number is 1")
end

var dict colors = {"red": "stop"}
match colors["red"] do
    "stop" -> print("Stop the car")
end
// colors["red"] is the dictionary's value type. A missing key aborts.

Matching Result

match content do
    Ok(data) -> process_data(data)
    Error(msg) -> Error("failed: ${msg}")
end
