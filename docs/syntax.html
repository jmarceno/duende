Comments

Single-line comments start with //. Duende also supports block comments /* ... */ and JSDoc-style block comments /** ... */. All comments are ignored by the compiler at this stage.

// This is a comment
print("Hello") // trailing comment

/* A block comment
   spanning multiple lines */

/**
 * JSDoc-style comment (currently ignored)
 */
int add(int a, int b) do
    return a + b
end

Blocks

Blocks are delimited by do and end. Function bodies and control structures use this form.

int main() do
    print("Hello")
end

Function parameters

Parameters use type name or named form type: name. Defaults are written with = and must be constant expressions. All defaulted parameters must trail non-default ones.

int f(int a, int b = 10) do
    return a + b
end

void greet(string: name) do
    print("Hello, ${name}")
end

// Calls
let int x = f(2)          // uses default b = 10
greet(name: "Duende")    // named argument call

// Mixing is allowed; unnamed fill left-to-right
let int y = f(2, b: 5)

Literals

  • Integers are 64-bit: 42
  • Floats are doubles: 3.14
  • Strings use double quotes and support interpolation.
  • Booleans: true, false
  • Lists: [1, 2, 3]; Dicts: {"k": 1}
  • Bytes: let bytes b = [1, 2, 255] (see Bytes)

String interpolation

Use ${expr} inside strings; optional format spec after |. See Strings.

let string name = "Duende"
let float ratio = 1.0 / 3.0
print("Hello ${name}, ratio=${ratio|%.2f}")

Operators

  • Arithmetic: +, -, *, /, % (modulo)
  • Comparison: ==, !=, <, <=, >, >=
  • Boolean: !, &&, ||
  • Indexing: a[i]; dict: d["key"]
