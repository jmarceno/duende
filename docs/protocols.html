Protocols

Home Structs & Frames

Definition

Protocols define required methods, and can provide default method implementations.

protocol Greeter do
  string greet(string name)

  int testFunc()

  string defaultGreet(string name) do
    return "Hello ${name}"
  end
end

Implementation

Use the @Implements(Name) annotation on a frame or struct.

@Implements(Greeter)
frame ConsoleGreeter do
  string greet(string name) do
    return "Hello, ${name}"
  end

  int testFunc() do
    return 0
  end
end

@Implements(Greeter)
struct ConsoleStructGreeter do
  string greet(string name) do
    return "Hello, ${name}"
  end

  int testFunc() do
    return 0
  end
end

var ConsoleGreeter g = ConsoleGreeter()
print(g.greet("World"))

let ConsoleStructGreeter sg = ConsoleStructGreeter()
print(sg.defaultGreet("Foo"))

Rules

  • An implementer must define every protocol method that has no default, with the same name and number of parameters; otherwise a compile error is emitted.
  • Default methods are added to the implementer. A method the implementer defines itself replaces the default.
  • Implementing a protocol never changes storage: a struct stays a value (copied, compared by its fields) and a frame stays a reference. See Structs & Frames.
  • Protocol methods are called directly on the struct or frame, or through an auto parameter, which is resolved at compile time for each type:
string report(auto s) do
  return s.describe()
end

A protocol name is not yet a variable or parameter type, so there is no implicit boxing or dynamic dispatch of structs.
