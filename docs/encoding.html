The std.encoding package offers friendly helpers for common encodings built on top of D's standard library: UTF-8/UTF-16, Base64, and Hex. It is provided via Duende's package system and requires no compiler changes.

Import

import std.encoding

Available functions

  • utf8Encode(s: string) -> bytes
  • utf8Decode(b: bytes) -> string
  • utf16LEEncode(s: string) -> bytes
  • utf16LEDecode(b: bytes) -> string
  • utf16BEEncode(s: string) -> bytes
  • utf16BEDecode(b: bytes) -> string
  • base64Encode(b: bytes) -> string
  • base64Decode(s: string) -> bytes
  • hexEncode(b: bytes) -> string
  • hexDecode(s: string) -> bytes
  • convertToString(encoding: string, data: bytes) -> string
  • convertToBytes(encoding: string, s: string) -> bytes

API

  • UTF-8: utf8Encode(string) -> bytes, utf8Decode(bytes) -> string
  • UTF-16 LE/BE: utf16LEEncode/utf16LEDecode, utf16BEEncode/utf16BEDecode
  • Base64: base64Encode(bytes|utf8) -> string, base64Decode(string) -> bytes
  • Hex: hexEncode(bytes) -> string, hexDecode(string) -> bytes
  • Generic conversions: convertToString(encoding, bytes), convertToBytes(encoding, string) where encoding can be utf-8, utf-16le, utf-16be, base64, or hex.

Example

import std.encoding

let string text = "Hello, 世界"
let bytes b8 = utf8Encode(text)
print(len(b8))
print(utf16LEDecode(utf16LEEncode(text)))
print(base64Encode(b8))
print(hexEncode(b8))

See examples/std_encoding.du for a more complete scenario with round-trips and conversions.
