Duende provides lightweight async-style concurrency via a package, built on D fibers. Import std.async to use it without changing the compiler.

Overview

  • Cooperative scheduler implemented in D using core.thread.fiber.
  • API: spawn(fn), run(), yieldNow(), sleepAsync(ms), awaitReadable(handle, timeoutMs=0).
  • Works alongside std.networking helpers; you can mix blocking and non-blocking flows as needed.
  • Cross-platform: uses select() on POSIX/Windows when awaiting socket readability.

Available functions

  • spawn(fn: () -> void) and spawn(fn: (int) -> int)
  • run()
  • yieldNow()
  • sleepAsync(ms: int)
  • awaitReadable(handle: int, timeoutMs: int = 0)

Usage

import std.async
import std.networking

int main() do
  let int port = 9101
  var auto listener = tcpListen(port)
  spawnEchoOnce(listener)

  spawn({ ->
    var auto c = tcpConnect("127.0.0.1", port)
    tcpSend(c, "hello", true)
    yieldNow() // let other tasks run
    var string line = tcpRecvLine(c)
    print(line)
    tcpClose(c)
  })

  run() // process all tasks
  tcpClose(listener)
  return 0
end

Sockets and non-blocking IO

For advanced scenarios, use awaitReadable(handle, timeoutMs) to cooperatively wait for a socket to be ready without blocking the scheduler. The handle can be obtained from std.networking sockets via sock.sock.handle.

import std.async
import std.networking

var auto c = tcpConnect("127.0.0.1", 8080)
// await readable for up to 1000ms before trying to recv
awaitReadable(c.sock.handle, 1000)
var string data = tcpRecvLine(c)

Notes

  • The scheduler is cooperative: a task must yield (via yieldNow, sleepAsync, or awaitReadable) to let others progress.
  • run() processes tasks until the queue empties.
