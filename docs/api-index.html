API Index

Home Packages

Quick, alphabetical index of the language- and provider-level APIs. Each entry links to the page that documents the functions in detail.

Core built-ins

  • I/O: print(x), input(), input(prompt)
  • System: osName(), osVersion(), cpuArch(), args()
  • sleep: sleep(ms)
  • Result & Maybe: Ok(...), Error(...), Some(...), None, ? else, safeCast(T, value)

Standard library providers

  • Strings: methods like split, replace, toUpperCase, contains, format
  • Regex: regex("..."), test, matchFirst, matchAll, replace
  • Bytes: construction, indexing, toString, length
  • Encoding: toUtf8/fromUtf8, toBase64/fromBase64, toHex/fromHex
  • Hashing: md5, crc32, crc64, sha1, sha224, sha256, sha384, sha512, sha512_224, sha512_256, murmurhash3
  • JSON: parseJSON, and JsonValue accessors (.str, .floating, .array, indexing)
  • XML: parsing, querying, modifying, and generating XML
  • Math: abs, min, max, floor, ceil, round, sqrt, pow, log, exp, trig and degree helpers
  • Dates & Times: now, utcNow, date, dateTime, parseDate, formatDate, arithmetic, and time zones
  • File I/O: readText, writeText, appendText, readBytes, writeBytes, appendBytes, readLines, writeLines, appendLines, fileExists, dirExists, deleteFile, listDir, makeDir, removeDir, getCwd, fileSize, getMetadata, joinPath
  • Processes: execute, executeShell, spawnProcess, pipeProcess, pipeShell, wait, tryWait, kill, readAllStdout, readAllStderr
  • Networking: TCP (tcpListen, tcpAccept, tcpConnect, tcpSend, tcpRecvLine), UDP (udpOpen, udpSendTo, udpRecv, udpRecvFrom, udpLocalPort)
  • Async: futures, scheduling helpers
  • Terminal: TTY detection via terminal module helpers

Collections

  • Lists & Dicts: fields (.length, .keys, .values), methods (push, pop, join), iteration
  • Pattern Matching: match lists, dicts, regex, ranges

User-defined types

  • Structs & Frames: definitions, methods, immutability/mutability
  • Enums: declaration and comparisons
  • Protocols: interfaces with default methods

Providers and integrations

  • Packages: provider discovery, manifests, and dub integration
  • Vibe.d: HTTP/HTTPS, WebSocket, TLS, async ops, logging, FS, processes
